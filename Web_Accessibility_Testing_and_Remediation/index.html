Accessible Web Demo

A small demo site for practising inclusive web design and accessibility testing.

Features Contact form Testing checklist

Accessibility features demonstrated

  • Semantic HTML landmarks and a logical heading structure.
  • A keyboard-accessible skip link and visible focus indicators.
  • Explicit labels and helpful error messages for form fields.
  • Responsive layout and a high-contrast visual design.

Learning note: These are examples to test, not a claim of WCAG conformance. Use the checklist below and verify the page with manual and automated checks.
